Scope: approved Task 6, plus review of Task 5 after a manual main-model switch. Review was performed in the same conversation; it is not an independent agent review.

## Changes and compatibility

- `Engine` delegates every pass to `ApiEngine`, including legacy `UseApi=false` settings. `DataFolder`, `Latest`, `Run`, `Stop`, and session-shared `ApiPacer` / `SignedLinkCache` remain. A stop arriving immediately before `Run` is retained; a concurrent second `Run` is rejected.
- Removed `CloudFiles.cs`, native placeholder hydration, client queues, client process discovery/restart, the `cldapi.dll` prerequisite and the `--probe` command. `PrerequisiteStatus.PlatformReady` checks Windows, architecture and Framework only. Windows 10 1709+ / Windows 11, Framework 4.7.1+, x64/x86 builds remain the declared baseline.
- Removed the method selector and its dormant client UI branches. API credentials, destination, transfer settings and five pass modes remain. The OAuth link occupies the removed selector's header area. The settings card is shorter by one row.
- Legacy `Folder`, `Concurrency`, `RestartClient`, `UseApi` fields remain deserializable. They cannot select native execution. Existing Desktop pass strings and counters remain displayable. Client history is not imported into API history; its original journal is retained byte for byte.
- `BrowserCatalog.Load(..., false, ...)` remains a read-only legacy history reader. The active dashboard always loads API inventory/history. Shared history, file selection, path checks, preservation, range-map and partial-file code remain.
- Project and build scripts already compile `src/*.cs`; no explicit project-file item removal is needed.

## Task 5 review finding

The exceptional drain in `ApiEngine.Run` saved all completed jobs to history, including a version excluded during metadata refresh in DownloadErrors mode. A subsequent publication/report failure could therefore overwrite previous-version error evidence. `ModePolicyTests.MetadataChangedFailure` injects an exception after metadata completion and reproduced the overwrite before the fix. Both normal completion and exceptional cleanup now use `RecordResult`, which preserves history for excluded versions. The focused mode-policy suite passes.
