# Baseline and compatibility map

Base commit: 234fea2f415007a698d0faa834e1136f3d3891fd, public version 1.1.2.
Both full offline self-tests passed outside the sandbox on 18 October 2026. Reports: x64.txt and x86.txt. These test the host Windows; they do not verify every Windows 10 release, physical power removal or a real Yandex account.

| Function/type | Consumers at baseline | User data | Decision / coverage |
|---|---|---|---|
| Engine | MainForm, Tests, tests for shared pacer/cache | Dispatches API HistoryStore; old client history under RootKey | Keep small API facade; no automatic import/delete of client journals |
| YandexCloudNative | Engine native branch, Program --probe, native-only Tests | Placeholder operations in the old client folder | Remove execution after API tests cover Stop and integrity; keep reparse-point protection in API |
| PrerequisiteStatus | Program, MainForm prerequisite display, Tests | None | Keep Windows/Framework/architecture; remove CloudFiles/client requirement |
| RunMode | Models/FileRules, ApiEngine, Engine, ScanSessionPolicy, MainForm, tests | PassResult.Mode is a string; history stores file status independently | Keep five explicit numeric values; read old Mode strings without enum parsing |
| Settings | MainForm, Engine, ApiEngine, TokenVault, tests | data/settings.json public fields; token excluded by ScriptIgnore | Retain old fields for reading where required, no serializer migration |
| PassHistory | MainForm, PassStatistics, retention tests | data/passes.jsonl, JavaScriptSerializer dates, string Mode/Method | Keep old/unknown strings, neutral label; no destructive migration |
| HistoryStore / HistoryIndex | API, FileDashboard, compaction and repair code | API identity directory/history.jsonl and history.latest; path/version/status/hash | Keep authoritative JSONL and case-sensitive cloud identity; derivative index may rebuild |
| InventoryCache | ApiEngine, FileDashboard, inventory completeness tests | api-inventory/<identity>/inventory.json v1/v2/v3 | Preserve failed/pending folders; no storage redesign in this series |
| RangeMap / DurablePartial | API mapped/segment download, repair and migration tests | .ydr-download/.ydr-map, legacy .ydr-part/.ydr-state/.ydr-segments | Preserve byte format, checksums and import/recovery tests |
| FilePreserver | API finalization and recovery | preservation owner/intent/ledger/root files; preserved previous copies | Preserve ownership and intent recovery; add cancellable checks before transaction |
| AppUpdater | UpdateUi, Program --apply-update, UpdaterTests | Temp ZIP/package/helper/backup, installation files | Keep allowlist, SHA-256 and 100 MiB; never replace data |

Compatibility fixtures are generated by StartupReliabilityTests.Compatibility from literal legacy JSON/JSONL. They include Desktop and unknown modes, a legacy /Date(...)/ value, old Settings fields, mixed-case cloud file paths and a torn JSONL tail. Existing StartupReliabilityTests.Relocation, RangeMapTests, DurablePartialTests, HistoryCompactionTests and InventoryCompletenessTests cover partial bytes, interrupted migration and inventory v1/v2/v3. Fixtures contain no live credentials.

Only this clone is writable work. The running user's installed app and download directory are outside scope. Build/package shape remains the old Framework ZIP for this series.
