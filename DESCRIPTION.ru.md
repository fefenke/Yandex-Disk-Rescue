# Yandex Disk Rescue 1.0.2

- Получение ссылок и скачивание работают параллельно: по умолчанию 7 запросов ссылок и 20 загрузок. Оба значения можно настроить от 1 до 30.
- Два отдельных таймаута: ожидание ссылки и отсутствие данных файла. По умолчанию 3 + 3 секунды; время очереди и интервал запуска запросов не расходуют таймаут ссылки.
- Настраиваемый интервал запросов API: 25–1000 мс, по умолчанию 50 мс.
- «Бесконечные проходы» повторяют проблемные файлы с паузой 30 секунд. Автоматическое увеличение таймаута удалено.
- Обновлён гайд с объяснением настроек и ошибок. Блок обновлений расположен ниже.

Настройки и история сохраняются при обновлении. При первом переходе на новую схему начальные таймауты устанавливаются в 3 + 3 секунды и включаются бесконечные проходы; затем выбранные значения сохраняются.

Поддерживается обычный раздел «Файлы». Безлимитная автозагрузка фото и видео не поддерживается. Программа не гарантирует скачивание файлов, недоступных на сервере.
