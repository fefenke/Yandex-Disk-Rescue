# Yandex Disk Rescue 1.0.4

Бесплатное portable-приложение Windows для скачивания обычного раздела «Файлы» Яндекс Диска через API или официальный клиент. Независимый неофициальный проект, использующий технологию Яндекс Диска.

Докачка и части крупных файлов, общий лимит соединений, повторы после прогресса, Retry-After и адаптивная частота API, рабочие ссылки между проходами, свежая проверка версии начатого файла и контрольные точки 32 МиБ / 15 секунд с восстановлением после сбоя. Папки, категории, журнал, история и обновления приложения. RU / EN, Windows x64 / x86.

Безлимитная автозагрузка фото и видео не поддерживается. Программа не исправляет облачные оригиналы и не гарантирует доступ ко всем файлам. Подробные условия и ограничения: [README](README.md), [гайд](GUIDE.md), [изменения](RELEASE-NOTES.md).
