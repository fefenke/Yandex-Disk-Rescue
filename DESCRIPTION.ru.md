# Yandex Disk Rescue 1.0.0

Новый интерфейс, браузер папок и обновление приложения с сохранением настроек и истории.

- Боковое меню: настройки, обзор, файлы и папки, журнал и история проходов. При запуске открываются настройки; гайд доступен сверху.
- Компактный браузер папок с прогрессом, значками, поиском и фильтром нескачанных. Двойной щелчок открывает готовый файл или папку; контекстное меню показывает файл в Проводнике.
- Убраны мерцание при обновлении дерева, наложение длинных имён и лишние категории. Журнал сохраняет выделение и прокрутку, добавлен фильтр успешных событий.
- Настройки загрузки заблокированы на протяжении сканирования, прохода и пауз автоповтора. Исправлены гонки при остановке; добавлена локальная диагностика ошибок интерфейса.
- Проверка обновлений с GitHub: автоматическая с возможностью отключения и ручная. Установка после согласия, проверка SHA-256, сохранение папки data и откат при ошибке замены файлов.
- Переписаны встроенный гайд, README и инструкции по режимам, докачке и обновлению. Скриншоты используют демонстрационные данные.

API сохраняет поддержку HTTP Range: докачка возможна при поддержке сервера и совпадении версии файла; перед завершением проверяются размер и доступный MD5.

**Безлимитная автозагрузка фото и видео не поддерживается.** Только обычный раздел «Файлы». Серверные ошибки не исправляются, скачивание каждого файла не гарантируется.

Для ручного обновления сначала закройте приложение и сохраните свою папку data. Публичные ZIP содержат только программу и документацию, без пользовательской истории, логов и токенов.
