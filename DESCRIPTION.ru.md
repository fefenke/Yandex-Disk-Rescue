# Yandex Disk Rescue 1.0.5

Бесплатное portable-приложение Windows: докачка, единый файл с картой диапазонов, сохранение прежних копий, MD5/SHA-256 и повторы с учётом ограничений API. RU/EN, x64/x86, локальная история и зашифрованный токен.

Медиа, существующие только в безлимитной автозагрузке, сначала подготовьте в обычных папках через официальный сайт Диска. Это позволяет избежать повторного обхода пересекающихся источников и передачи сессионных данных сторонним сервисам. Подробности: [гайд](GUIDE.md), [решения](DESIGN-DECISIONS.md), [тесты](TESTING.md).
