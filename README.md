## Как начать

**API:** получите OAuth-токен через [полигон Яндекс Диска](https://yandex.ru/dev/disk/poligon/), вставьте его в приложение и выберите папку сохранения. `disk:/` — весь Диск, `disk:/Фото` — отдельная папка. Клиент Диска не нужен, нет ожидания его перезапусков; API может работать быстрее, но скорость зависит от сервиса и сети.

**Клиент Диска:** установите [Яндекс Диск](https://disk.yandex.ru/download), войдите в аккаунт и дождитесь окончания синхронизации. Выберите локальную папку Диска. При ошибках синхронизации клиент может перезапускаться.

Откройте **«Открыть гайд»** в приложении: там подробно описаны оба способа и сочетания режимов.

## Список и режимы

Верхний выбор API задаёт источник списка. **Сохранённый список** не требует нового обхода; при первом запуске создаётся один раз, незавершённый скан продолжается. **Обновить список** выбирайте, если добавили или изменили файлы в облаке. Автоповтор не обновляет список на каждом проходе.

| Режим | Какие файлы обрабатываются |
| --- | --- |
| Продолжить незавершённый проход | Непроверенные и прерванные пользователем попытки |
| Повторить ошибки сервера / синхронизации | Файлы с такими ошибками в истории |
| Повторить таймауты и сбои | Нулевые и частичные загрузки, другие неуспешные попытки |
| Повторить все нескачанные | Все нескачанные, включая непроверенные и проблемные |
| Начать проход с нуля | Весь список заново; корректные скачанные файлы не скачиваются повторно |

Обычный запуск: сохранённый список + повторить все нескачанные. После изменений в облаке: обновить список + повторить все нескачанные.

С галкой **«Повторять проблемные файлы»** сначала выполняется выбранный режим, затем повторяются ошибки и таймауты с паузой 30 секунд. «Стоп» отменяет запросы и ожидание. Когда проблемных файлов нет, цикл завершается. Неверный токен, отсутствие прав, критические локальные ошибки и неподтверждённая отмена требуют исправления.

## Статистика и данные

Карточки показывают найдено, скачано всего, скачано за проход, осталось и ошибки. «Осталось» включает все нескачанные, а размер текущего прохода зависит от режима. Вкладка **«Проходы»** сохраняет время, длительность, режим, результат и количество файлов; подробные отчёты создаются автоматически.

История, сохранённый список, отчёты и зашифрованный Windows DPAPI токен хранятся локально в `data` рядом с EXE. При обновлении сохраните эту папку. **Не публикуйте `data`.** Выпуски не содержат личных токенов, истории или логов.

Файлы учитываются по полному пути и версии; одинаковые имена в разных папках не объединяются. API проверяет размер и доступный MD5. Частичные файлы `.ydr-part` не считаются скачанными; при повторе загрузка начинается заново. Неизменившиеся ранее проверенные файлы сверяются быстрее; полный проход проверяет их снова.

Независимый проект, не официальный продукт Яндекса. Не восстанавливает удалённые файлы и не исправляет ошибки сервера. Безлимитная автозагрузка не поддерживается.
